# ARXML Composition / Port Viewer 使用说明书

**版本**：0.4.x  
**适用平台**：Windows（推荐）/ 已安装 Python 3.10+ 的环境  
**依赖**：PySide6、lxml；导出 PDF 报告另需 reportlab

---

## 1. 软件简介

本软件用于浏览与有限编辑 AUTOSAR ARXML，面向 Composition 结构、端口连接、SR/CS 链路、RTE Internal Behavior、System Data Mapping、一致性检查与规范校验等日常工作。

### 1.1 主要能力

- Composition / Application SWC 结构图浏览与导航
- Assembly / Delegation 连接关系查看、创建、重命名、删除
- SR/CS Port 全链路追踪（含嵌套 Delegation）
- 对照文件（Peer）跨文件 P↔R 对端匹配
- RTE IB：Runnable / Event / Port Access 等编辑
- System Data Mapping 增删改
- AUTOSAR 规范校验（XSD + 语义 + Vector 40329 N:M）
- 一致性检查与可勾选批量修复
- 按 SWC / Composition / SYSTEM 切片导出
- Undo / Redo（主文件与对照文件分栈）
- 工程配置旁路保存（`.arxml_viewer.json`）
- 轻量 OS/RTE Mapping 侧车（`<stem>.os_rte.json`：OsTask + Runnable→Task）

### 1.2 明确不做的范围

以下能力不在本软件目标内：

- ECUC / DaVinci RTE 工程级配置与导入
- 完整 DaVinci/Vector RTE 与 COM 栈（仅提供侧车 + 最小 C 骨架）
- 完整 COM 通信栈编辑
- 与 Vector 工程双向同步

## 2. 安装与启动

### 2.1 安装依赖

在仓库根目录执行：

```text
pip install -r arxml_viewer/requirements.txt
```

如需生成校验结果 PDF 或本说明书 PDF：

```text
pip install -r arxml_viewer/requirements-pdf.txt
```

或：

```text
pip install -e ".[pdf]"
```

### 2.2 启动

```text
python -m arxml_viewer
```

或：

```text
python arxml_viewer/run.py
```

可选：`run_viewer.bat`（若仓库中提供）。

### 2.3 自检

```text
python -m arxml_viewer.smoke_test
python -m arxml_viewer.tests.test_roadmap
```

主窗口大致分区：

| 区域 | 作用 |
|------|------|
| 左侧树 | 包 / Composition / SWC / Port / Interface / ADT / Mapping 等导航 |

## 4. 打开与工程配置

### 4.1 打开主文件

**File → Open ARXML…**（Ctrl+O）

打开后软件会：

1. 后台解析 ARXML
2. 状态栏显示规模（文件大小、Composition/Port 数量等）
3. 大文件（Ports≥800）时提示开启 **Limit ports**
4. 若开启「Validate on open」，约 1.2 秒后延后启动规范校验

### 4.2 对照文件（Peer）

用于 ZCUD / ZCUP 等成对文件跨文件对端查看：

| 菜单 | 说明 |
|------|------|
| File → Open peer ARXML… | 加载对照文件 |
| File → Clear peer ARXML | 清除对照 |
| File → Save peer ARXML… | 写回对照文件的未保存修改 |
| File → Swap: open peer as primary… | 对照切为主文件 |

说明：

- 跨文件 **P↔R 导航** 支持；**跨文件拖线建连不支持**（仅主文件 Composition 结构图）
- 对照编辑使用独立 Undo 栈（Edit → Undo/Redo peer）

### 4.3 工程配置

**Help → Save project config** 会在主 ARXML 旁生成 `.arxml_viewer.json`，可记住：

- 主/对照路径
- Limit ports
- 打开时是否校验

再次打开主文件时会询问是否加载对照。

## 5. 浏览与导航

### 5.1 结构图与链路图

| 控件 | 说明 |
|------|------|
| 结构视图 | Composition / SWC 框图 |
| 链路视图 | 当前 SR Port 的 Assembly/Delegation 全链路 |
| 分屏 | 左结构 + 右链路 |
| 弹出窗口 | 独立图窗，与主窗同步导航 |
| Limit ports | 限制图上端口数量，加速大文件绘图 |
| Nest preview | 嵌套 Composition 预览（若启用） |

### 5.2 连接线含义

| 类型 | 外观（典型） | 含义 |
|------|--------------|------|
| Assembly | 蓝实线 | P↔R，真正的收发对端 |
| Delegation | 紫虚线 | 外↔内同向透传，**不是**收发翻转 |

链路表「方向」列常见值：

- `P→R`：装配对端
- `同向P` / `同向R`：委托透传

### 5.3 查看对端

1. 在图或树中选中 Port
2. 右侧属性栏查看：①本侧 ②P↔R ③委托 ④链路端（含跨文件半链）
3. 或使用 **对端列表** / **跳转 P↔R 对端**
4. 已加载对照时，可匹配跨文件对端

### 5.4 查找

**Edit → Find…**（Ctrl+F）：按路径/名称定位对象。

---

## 6. 连线与连接器编辑

### 6.1 连线模式

1. 勾选工具栏 **连线模式**（或 Shift+拖）
2. 在 **Composition 结构图** 中从 Port 拖到另一 Port
3. 合法目标显示绿虚线吸附
4. 确认后创建 Assembly 或 Delegation；成功后 **保持连线模式** 可继续拖

注意：链路图 / 对照链路视图下不能跨文件建连。

### 6.2 菜单编辑

| 操作 | 菜单 / 快捷键 |
|------|----------------|
| 新增 Assembly | Edit → Add Assembly…（Ctrl+N） |
| 新增 CS Assembly | Edit → Add CS Assembly… |
| 新增 Delegation | Edit → Add Delegation…（Ctrl+D） |
| 重命名连接器 | 底表选中 → Rename… |
| 删除连接器 | 底表选中 → Delete… |
| 批量补委托外口 | 批量委托（带预览勾选） |

所有内存编辑需 **File → Save** 才写回磁盘。

## 7. RTE / Mapping / Port 编辑

### 7.1 Data Mapping

- Edit → Add / Edit / Delete Data Mapping…
- 无 SYSTEM-MAPPING 时可先创建 SYSTEM stub（若菜单提供）

### 7.2 Internal Behavior

- Add Runnable / Set Symbol
- Add Timing / Init / DataReceived Event
- Set Period、Rebind Event→Runnable
- Port Access 增删

### 7.3 Port / 对象重命名

- Edit → Rename selected object…（F2）
- 适用于 Port / ADT / IDT / Interface / Runnable / Event 等（以树选中为准）

### 7.4 OS/RTE Mapping（侧车，非 ECUC）

与主 ARXML 同目录的 `<文件名>.os_rte.json` 描述轻量 OsTask 与 Runnable→Task：

```json
{
  "version": 1,
  "ecu": "EcuStub",
  "tasks": [
    { "name": "OsTask_10ms", "priority": 10, "schedule": "FULL", "type": "EXTENDED" }
  ],
  "mappings": [
    {
      "task": "OsTask_10ms",
      "swc_prototype": "/Path/To/Proto",
      "runnable": "/Path/To/RE",
      "position": 0
    }
  ]
}
```

- 打开主文件后若存在侧车会自动加载
- `Tools → OS/RTE Mapping…`：增删 Task / Mapping
- `Tools → Import/Export OS/RTE Mapping CSV…`
- `Tools → Generate RTE skeleton (C)…`：按 Task 生成 `Rte_Task_*.c` / `Rte_Tasks.h`（**最小骨架**，非 DaVinci 完整 RTE）
- `File → Save / Open OS/RTE Mapping`
- 左树 `OS Tasks (overlay)`；一致性检查：悬空 REF、未映射 Runnable、有 Access 未映射 Task 等

### 7.5 对端图（1:N）

- 工具栏 **对端图**：本侧与各对端的**嵌套 Composition 链路**并排
- Application Port 会自动沿 Delegation **抬升**到最外层 `_P/_R` 再匹配对端
- 默认只展开 1 条对端全链，其余为占位，**点击占位可展开**（大文件性能）
- Find 输入 `1n` 可列出 Assembly 一对多的 P-Port

## 8. 撤销与重做

| 菜单 | 作用 |
|------|------|
| Edit → Undo（Ctrl+Z） | 撤销主文件编辑 |
| Edit → Redo（Ctrl+Y） | 重做主文件编辑 |
| Edit → Undo peer | 撤销对照文件编辑 |
| Edit → Redo peer | 重做对照文件编辑 |

说明：

- 主/对照 **分栈**，互不影响
- Undo 按编辑类型做轻量快照（连接器 / Mapping / IB / Port 等），降低大文件内存压力

## 9. 一致性检查

**Edit → Consistency check…**

作用：检查连接器端点、方向、P↔R 孤儿、Mapping 悬空等（偏工程连通性）。

与规范校验的区别：

| 项目 | Consistency check | Validate AUTOSAR |
|------|-------------------|------------------|
| 侧重 | 模型连通 / 对端 / Mapping | XSD + 语义规范 + N:M |
| 可修复 | 坏连接删除；ADT/IDT/DataMap 去重、UUID 重复（本仓库 `tools/` 脚本写出 beta） | 规范校验对话框亦可直接点脚本修复 |
| 后门 | 空壳 Constant、N:M/DG_R（导出平台问题；`tools/` 后门写出 beta，非默认流程） | 同上 |
| 对照 | Target=peer 可修对照 | 校验当前选定文件/快照 |

操作：

1. 按级别过滤（Error / Warning / 可修复）
2. 勾选「修复」列 → **应用勾选的修复**
3. Target=peer 的项写入对照模型，需 **Save peer**
4. 双击行可跳转

## 10. AUTOSAR 规范校验

唯一完整引擎：`arxml_schema_validator` + `AUTOSAR_00046.xsd`（含 Vector 40329 N:M）。

### 10.1 菜单

| 菜单 | 说明 |
|------|------|
| Validate AUTOSAR…（Ctrl+Shift+V） | 校验磁盘上的主文件 |
| Validate with pending edits… | 将未保存修改写出临时快照再校验（不改源文件） |
| Validate current Composition/SWC… | 全量跑引擎后，结果按当前路径过滤 |
| Cancel validation（Ctrl+Shift+C） | 取消进行中的校验阶段 |
| Validate on open (deferred) | 打开后空闲再自动校验 |

可用环境变量 `ARXML_XSD` 覆盖 XSD 路径。

### 10.2 结果对话框

- 按 **级别 / 类别（XSD、N:M、REF…）/ 关键字** 过滤
- **Error 全量显示**，不截断
- 双击：路径跳转模型；`XSD Ln:` 可预览源文件行并打开
- **保存结果…**：导出 TXT 或 PDF；可打开所在文件夹

### 10.3 与一致性检查如何选用

- 查「规范是否合规、N:M、XSD」→ Validate AUTOSAR  
- 查「连没连上、对端缺不缺、坏连接能不能删」→ Consistency check

## 13. 大文件建议

1. 开启 **Limit ports**
2. 打开自动校验可关闭，需要时再手动 Validate
3. 可用 **Validate current Composition/SWC** 缩小关注面
4. 长时间校验可用 **Cancel validation**
5. 状态栏关注规模提示（如 Ports 过多）

## 14. 常见问题

**Q：校验提示找不到 XSD？**  
A：确认存在 `arxml_viewer/AUTOSAR_MMOD_XMLSchema/AUTOSAR_00046.xsd`，或设置 `ARXML_XSD`。ARXML 里写的 `AUTOSAR_4-4-0.xsd` 与包内正式文件名不同，完整引擎使用 `AUTOSAR_00046.xsd`。

**Q：为什么没报 N:M？**  
A：请使用 **Validate AUTOSAR**（完整引擎）。不要使用已移除的「语义快检」路径。

**Q：改了模型校验却还是旧结果？**  
A：默认校验磁盘文件。未保存修改请用 **Validate with pending edits**。

**Q：对照文件修了没生效？**  
A：确认 Consistency 项 Target=peer，并执行 **Save peer**。

**Q：连线一点击就跳链路？**  
A：请勾选连线模式后在结构图拖拽；连线模式下点击 Port 不会跳转链路图。
